# Research Engine — 论文构建引擎

把内容丢进 Cursor 对话框，系统**自动判断该做什么**。不需要记任何触发词。

- 丢一个知网 URL → 自动走正式论文阅读流程
- 丢一个 ArXiv 链接 → 自动走轻量泛读
- 问"有没有人研究过 X" → 自动并行检索
- 什么都不说，周一打开 Cursor → 自动生成进度简报

轻量操作直接办，重操作（深度分析、多数据库浏览器检索）先征求同意。

## v2.2 更新了什么（2026-03-13）

> 核心变化：**用户不需要记触发词**。智能路由自动判断内容类型并调度。

| 改动 | 说明 |
|------|------|
| **智能路由** | 用户不需要记触发词。丢内容进来，系统根据 URL 域名、文件类型、内容关键词自动判断走"读"还是"泛读"还是"查"。轻量操作直接办，重操作（深度分析、多库浏览器检索、大规模引文展开）先征求同意。 |
| **新增「泛读」模式** | ArXiv/博客/公众号/AI/社科类文章走轻量流程：一句话+核心洞见+跨域连接，30秒完成。发现实质性连接时提示升级为正式"读"。 |
| **新增「论」动作** | 每累计读完3篇论文自动提示。综合所有选题判决，评估选题可行性，更新论点骨架，给出下一步行动。不再是读完就散，每一次阅读都必须回答"这跟我的选题有什么关系"。 |
| **新增「脉搏」动作** | 每周一自动生成进度简报：距开题N周、已读N篇、论著目录N条、检索覆盖率N%、论点骨架进度、下次汇报需准备什么。用于对抗"忙了一周但不知道推进了什么"。 |
| **新增 argument-skeleton.md** | 论点骨架文件。候选选题多维评估表（材料/学术史/方法论/创新/规模）、累计判决记录、论证结构初步搭建、深度分析洞见回收。这是唯一允许修改（而非仅追加）的核心文件。 |
| **「读」模板升级** | 新增"选题判决"必填字段：每读一篇论文必须对每个候选选题给出 ⊕支持/⊖削弱/○无关/？待定 的明确判断，附一句话理由。 |
| **深度分析标准化** | 李继刚分析框架（系统分析/看本质/降秩/概念解剖）从"可选叠加"升级为"重要论文必做"。触发条件：被3+篇已读论文引用、直接涉及候选选题、提出新概念、用户指定。分析结果必须同步写入论点骨架。 |
| **知识图谱 TODO** | 预设了知识图谱的完整设计方案（节点/边/自动检测规则），但标注为未来 TODO——启动条件：论著目录超过80条 或 笔记超过15篇。当前阶段手动可控，不提前投入。 |
| **核心文件从3个变4个** | research-journal.md + search-matrix.md + bibliography.md + **argument-skeleton.md** |
| **协同图更新** | 完整反映新的六步闭环流程和文件写入关系 |

### v1 → v2 的设计逻辑

v1 的四步闭环（搜-读-记-追）解决了"输入"问题——能高效地找到论文、读论文、记笔记、追线索。但它有一个根本缺陷：**整个系统面向输入优化，没有面向输出的机制**。你可以读100篇论文，笔记写得整整齐齐，但论文一个字也没推进。

v2 加入的「论」和「脉搏」就是为了堵住这个漏洞：
- 「论」强制你从阅读中提炼论点——不是又做一次漂亮的框架分析，而是回答"我的选题确认了什么、否定了什么、还缺什么"
- 「脉搏」让你每周看到研究进度与开题 deadline 的对比——10周倒计时不是摆设

## 仓库结构

```
research-engine-skill/
├── SKILL.md              ← Cursor Skill 定义（安装到 ~/.cursor/skills/research-engine/）
├── README.md
├── thesis-timeline.md    ← 开题时间线与汇报节点
└── notes/                ← 研究数据（跨设备同步的核心）
    ├── research-journal.md    按问题分节的读书笔记
    ├── search-matrix.md       检索词矩阵
    ├── bibliography.md        论著目录（侯公规范）
    └── argument-skeleton.md   论点骨架（唯一允许修改的文件）
```

## 安装

```bash
# 1. 克隆仓库
git clone https://github.com/seasidedog24/research-engine-skill.git ~/Documents/research-engine-skill

# 2. 安装 Skill 到 Cursor
mkdir -p ~/.cursor/skills/research-engine
cp ~/Documents/research-engine-skill/SKILL.md ~/.cursor/skills/research-engine/

# 3. 软链接笔记目录（让 Skill 读写的路径指向仓库内的文件）
ln -sfn ~/Documents/research-engine-skill/notes ~/Documents/notes
```

> **跨设备同步**：在新设备上 clone 后执行上面 3 步即可续跑。
> 研究数据改完后 `cd ~/Documents/research-engine-skill && git add -A && git commit && git push`。

## 使用方式

**不需要记任何触发词。** 直接把内容丢进 Cursor 对话框：

| 你做什么 | 系统自动做什么 | 是否需要你确认 |
|---------|--------------|--------------|
| 丢一个知网/华艺 URL | 正式论文阅读+笔记+选题判决 | 否 |
| 丢一个 ArXiv/公众号链接 | 轻量泛读（一句话+洞见+跨域连接） | 否 |
| 丢一个 PDF/DOCX 路径 | 正式论文阅读 | 否 |
| 问"有没有人研究过 X" | 并行多源检索 | 否 |
| 提到某篇已读论文+"出发" | 引文网络展开 | 展开范围大时会问 |
| 什么都没做，周一打开 Cursor | 自动输出进度简报 | 否 |
| 累计读完3篇论文 | 提示做选题评估 | 你可以拒绝 |
| 论文满足深度分析条件 | 完成基础笔记后问你 | 是（消耗大） |

如果你想手动指定模式，也可以直接说：`巡` `查` `读` `泛读` `追` `盘` `论` `脉搏`

## 设计原则

- **侯旭东检索方法论**硬编码为不可违反的约束（竭泽而渔、多关键词交叉、按问题逻辑排列……）
- **李继刚深度分析框架**从"可选叠加"升级为"重要论文必做"
- **论点骨架**（argument-skeleton.md）从第一天开始构建，随研究动态演化
- **知识图谱**标记为未来 TODO，当论著目录超过80条时启动

## 四个核心文件

| 文件 | 作用 |
|------|------|
| `research-journal.md` | 按问题分节的读书笔记，只追加不删除 |
| `search-matrix.md` | 检索词矩阵，持续进化 |
| `bibliography.md` | 按侯公规范编制的论著目录 |
| `argument-skeleton.md` | 论点骨架，唯一允许修改（而非仅追加）的文件 |
