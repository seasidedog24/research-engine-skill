# Research Engine - 学术研究闭环操作系统

基于 Cursor IDE 的学术文献检索、阅读、记录、追踪闭环工作流。专为中国古代史（秦汉魏晋南北朝）研究设计，可适配其他人文学科。

## 核心功能

**搜-读-记-追**四步闭环，五个触发词：

| 触发词 | 功能 |
|--------|------|
| `巡` | 从已知论文出发，沿引文网络系统扩展学术认知 |
| `查 XX` | 多源并发检索（知网/华艺/CiNii/WebSearch） |
| `读这篇` | 抓取全文，生成结构化读书笔记 |
| `追线索` | 从笔记中提取新检索方向 |
| `盘一下` | 检索词矩阵自检，发现覆盖盲区 |

## 产出物

| `bibliography.md` | 论著目录，按侯公规范编制 |

## 方法论基础

基于侯旭东《研究综述的写作要点及搜集论著的途径》和《博士硕士开题报告写作流程》中的检索方法论：

1. 论著搜集"竭泽而渔"
2. 多关键词分组交叉检索
3. 断代史、专题史著作也要翻
4. 从论著注释中二次搜集
5. 按问题逻辑排列，不按时间罗列
6. 归纳共识与分歧，分析分歧原因
7. 史料与论著并读
8. 归类意识——与前后时代、世界范围同类问题联系

## 安装

1. 将 `SKILL.md` 放入 `~/.cursor/skills/research-engine/`
2. 创建三个笔记文件：
   - `~/Documents/notes/research-journal.md`
   - `~/Documents/notes/search-matrix.md`
   - `~/Documents/notes/bibliography.md`
3. 在 Cursor 中对 AI 说"巡"或"查 XX"即可触发

## 适配其他学科

修改 SKILL.md 中的：
- 用户背景（时段、方向）
- 检索词矩阵分组
- 数据源优先级（如西方史研究可提升 JSTOR/ProQuest 优先级）
- 笔记的问题分节

## 依赖

- Cursor IDE（含浏览器 MCP 工具）
- 清华大学图书馆账号（或其他高校图书馆，需调整 tlink 配置）
- 可选：李继刚提示词工具集（用于深度论文分析）
